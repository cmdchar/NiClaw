# ClawX AI OS Mobile Companion

This is the mobile frontend for ClawX AI OS, built with React Native (Expo).

## Getting Started

1. Install dependencies: `npm install`
2. Start the project: `npx expo start`
3. Connect to your Desktop AI OS using the **Secure Pairing QR Code** in Settings.

## Architecture

- **Communication:** Connects to the Desktop Host API via WebSocket/HTTP.
- **Security:** Uses the session token generated by the Desktop OS.
- **Capabilities:** Chat, Workspace Management, Remote Approval, and Voice Commands.

## Development

The mobile app mirrors the desktop's Unified API Client for consistent state management.
