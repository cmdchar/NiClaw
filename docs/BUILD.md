# ClawX AI OS - Build & Update Instructions

This document provides detailed instructions on how to build, package, and manage updates for the ClawX AI Operating System.

## Development Setup

1.  **Environment**: Ensure you have Node.js 22+ and pnpm 9+ installed.
2.  **Initialization**:
    ```bash
    pnpm run init
    ```
3.  **Run in Dev Mode**:
    ```bash
    pnpm dev
    ```

## Packaging & Distribution

To create production-ready installers for your platform:

-   **macOS**: `pnpm package:mac`
-   **Windows**: `pnpm package:win`
-   **Linux**: `pnpm package:linux`

Artifacts are generated in the `release/` directory.

## GitHub Release & Auto-Update Flow

ClawX AI OS uses **GitHub Releases** as the primary update provider.

### To Push a New Update:

1.  **Update Version**: Update the version in `package.json`.
2.  **Build Release**: Run the package command for all platforms.
3.  **Create GitHub Release**:
    -   Go to [GitHub Releases](https://github.com/ValueCell-ai/ClawX/releases).
    -   Draft a new release with a tag matching your `package.json` version (e.g., `v0.5.0`).
    -   Upload the installers from the `release/` folder (`.dmg`, `.exe`, `.deb`, `.AppImage`).
    -   Include the `latest.yml` (mac), `latest-linux.yml`, and `latest.exe.yml` (win) files generated by `electron-builder`. These are critical for the auto-updater.

### Verification:
The app's built-in updater (`electron/main/updater.ts`) will automatically detect the new release on GitHub. Users will see a prompt to download and install the update.

## Remote Server Deployment (Debian)

To run the AI OS on a remote Debian server and control it from Windows/Android:

1.  Transfer `scripts/install-debian.sh` to the server.
2.  Run the script: `bash install-debian.sh`.
3.  The systemd service `clawx-ai-os` will start the OS in headless mode.
4.  Use the Windows Desktop app or Android app to pair via QR code/Token found in the server logs or remote configuration.
